# Plans to move to gh-optivem

These plans need changes in the `optivem/gh-optivem` repo (code, templates or a release), not in shop. Shop treats gh-optivem as **read-only** (user decision, 2026-11-06): no shop session edits, commits or pushes there.

Move each plan into gh-optivem's own `plans/` and run it from a gh-optivem session. Once a plan is moved, delete it here. If a plan leaves a shop-side follow-up (e.g. re-adding a config key after a gh-optivem release), keep only that follow-up as a new shop plan.
